# Packaging Guide

This project uses Electron + electron-builder for cross-platform installers.

## 1) Prepare runtime bundle

From repo root:

- macOS: `python3 packaging/scripts/bundle_scanner_runtime.py --target macos`
- Linux: `python3 packaging/scripts/bundle_scanner_runtime.py --target linux`
- Windows: `python3 packaging/scripts/bundle_scanner_runtime.py --target windows`

## 2) Build desktop installer

From `apps/desktop`:

1. `npm install`
2. `npm run dist`

Output installers will be generated by electron-builder in `apps/desktop/dist/`.

## Notes

- The desktop app uses bundled runtime first; system Python is fallback for dev mode.
- Scanner source is bundled into app resources as `runtime/scanner`.
